## 我做项目的方式

```text
从一个具体问题出发
→ 写出能观察中间过程的最小实验
→ 记录失败、边界与自己的解释
→ 补上测试、文档和真实运行验证
→ 再进入下一轮迭代
```

我会尽量区分“代码已经实现”“自动化测试通过”“浏览器已经验收”和“生产已经部署”。仓库里既有完成的能力，也有正在学习和验证的部分；真实进度比包装得像已经解决一切更重要。

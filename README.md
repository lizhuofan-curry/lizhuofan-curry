## 我正在探索什么

我喜欢从一个小问题开始：模型为什么选了这个工具？一个 Token 是怎么来的？AI 给出的讲解，能不能让人真正记住？于是有了几条并行的实践路线：

| 方向 | 目前的实践 |
|---|---|
| 从“会用 Agent”到“能解释 Agent” | 从 ELIZA、ReAct、多智能体框架一路学到自制 HelloAgents，保留中文笔记、代码演进和讨论帖。 |
| 从 Tokenizer 理解大模型 | 手写 BPE，再观察 Byte-Level BPE、显存与分布式训练基础；数据管线和模型训练继续推进。 |
| 让 AI 帮助真正的学习 | 用问渠探索原文证据、主动回忆与错因诊断；用拾词把英文材料里的生词带回真实语境。 |
| 把研究与工程连接起来 | 持续学习 PyTorch、EEG / BCI 和软件工程；关注可复现环境、测试、清楚的运行说明。 |

## 我的学习方式

```text
先追问一个具体问题
    ↓
写一个能观察中间过程的小实验
    ↓
记录边界、失败和自己的解释
    ↓
补运行说明、测试与展示，再继续迭代
```

仓库里既有完成的功能，也有还在推敲的实现。我更愿意把真实进度写清楚，而不是把学习项目包装成已经解决一切的产品。
